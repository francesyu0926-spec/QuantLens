## 1. 产品概述

QuantLens 面向个人投资者与量化爱好者，在**单机本地**环境提供：

| 能力域 | 说明 |
|--------|------|
| 行情与图表 | WebSocket 推流 + REST 快照；Lightweight Charts K 线；多周期单/双/四图 |
| 技术指标 | EMA、布林带、成交量、VP、MACD/RSI 副图 |
| 策略信号 | 后端规则扫描 + 前端自选回填；声音/Webhook/系统通知 |
| 研究与 AI | 多周期共振雷达、结构化 AI 研报、智能解读（白话 Tooltip） |
| 模拟与复盘 | 纸面交易、止损风控测算、EMA 简易回测、复盘笔记 |
| 基本面增强 | PE/PB/行业/市值、主力净流入（A 股） |
| 数据资产 | 本地 SQLite（K 线缓存 + 用户数据）；JSON/CSV 导出与跨端同步 |
| 小白模式 | 白话看盘、单图专注、标记价位、模拟练习、条件选股简化 UI |
| 行情增强 | 大盘脉搏条、板块同业弹窗、条件选股（universe + 指标扫描） |

默认构建为 **A 股专用模式**（`A_SHARE_ONLY`）：红涨绿跌、6 位代码、交易时段校验。后端可通过配置扩展加密货币（CCXT）、美股（yfinance），见 `README.md`。

## 2. 系统架构

```
┌─────────────────────┐       WebSocket / REST        ┌──────────────────────────┐
│  React 终端 UI      │ ◄────────────────────────────► │  FastAPI 网关 (8765)      │
│  Vite :1420         │                                │  /ws · /klines · /sync    │
└──────────▲──────────┘                                └────────────┬─────────────┘
           │ Tauri WebView (可选)                                    │
┌──────────┴──────────┐                                             ▼
│  Tauri (Rust)       │                               ┌──────────────────────────┐
│  托盘 · 全局快捷键   │ ◄── sidecar ──► (可选)        │  MarketCollector         │
│  迷你看盘 · 通知     │                               │  指标 · 规则 · SQLite    │
└─────────────────────┘                               └──────────────────────────┘
```

| 层级 | 技术 | 职责 |
|------|------|------|
| 展示层 | React 18 + TypeScript + Vite | 布局、图表、自选、设置、状态机 |
| 图表 | Lightweight Charts | K 线、指标叠层、十字光标、标记 |
| 引擎层 | FastAPI + asyncio | WS 广播、K 线聚合、指标计算、信号扫描 |
| 数据源 | AKShare / CCXT / yfinance | 按标的类型选路 |
| 持久化 | SQLite `quantlens.db` | K 线缓存、`user_data` JSON 键值 |
| 桌面 | Tauri 2 + plugins | 托盘、Alt+Q、通知、迷你窗 |

## 3. 运行环境与启动

### 3.1 环境要求

| 组件 | 要求 |
|------|------|
| Node.js | 18+（`frontend`） |
| Python | 3.11+（`backend`） |
| Rust | 仅 Tauri 桌面打包时需要 |

### 3.2 启动步骤（Web 开发）

**终端 1 — 引擎**

```powershell
cd backend
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python run.py
```

默认监听 **http://127.0.0.1:8765**。

**终端 2 — 前端**

```powershell
cd frontend
copy .env.example .env
npm install
npm run dev
```

默认 **http://localhost:1420**。  
环境变量：`VITE_API_URL`、`VITE_WS_URL`（可选，指向引擎地址）。

**可选脚本**：`scripts/dev-backend.ps1`、`scripts/dev-frontend.ps1`。

### 3.3 桌面端

```powershell
cd frontend
npm run tauri dev
```

关闭主窗口时**最小化到托盘**（非退出）。可在 `src-tauri/binaries/` 放置 sidecar 引擎以开机拉起 Python。

## 5. 功能说明

### 5.1 连接状态（ConnectionStatusCapsule）

表示**传输层与轮询链路**，不等同于「单只标的 K 线一定成功」。

| 状态 | 圆点/文案 | 含义 |
|------|-----------|------|
| 盘中 + 已连接 | 亮绿（品牌旁） | 数据连接正常，按间隔同步（A 股约 5s） |
| 收盘 + 仍在线 | 半透明绿 | 链路正常，盘中行情已结束，快照轮询 |
| 休市/未连接 | 灰 | 日历休市或 WS 未连接 |
| 连接中/重连 | 琥珀闪烁 | 建立或恢复连接 |
| 失败 | 红，可点击 | 触发 `onReconnect` |

悬停 **friendly** 文案示例：

- 盘中：`数据连接正常，每 5s 同步`
- 盘后在线：`连接正常 · 已收盘 · 每 5s 快照`
- 连接正常但当前标的拉取失败：`连接正常 · 当前标的行情暂不可用`

交易时段由 `isAShareSessionOpen()`（Asia/Shanghai，周一至周五 9:30–11:30、13:00–15:00）决定顶栏文字，与连接点独立。

---

### 5.2 图表工具栏（ChartToolbar）

**周期**：`1m` `5m` `15m` `1h` `4h` `1d` — 作用于**当前激活分屏格**（多图时须先点选子图）。

**主图开关**：EMA · BOLL · VOL · VP（量价分布，可选）

**副图**（单图）：MACD 或 RSI 二选一；双图/四图默认隐藏副图以省高。

**画线 / 标记价位**

- **专业版**：「画线工具 ▾」下拉；**Alt + 点击**主图添加水平线；现价 / ±2% 止损止盈快捷项；触及价位可提醒（🔔）
- **小白版**：「标记价位 ▾」；下拉内可**开启点图标记**（单击主图即可画线，**Esc** 退出）；工具栏下方 **已标记** 芯片条支持单条删除与**全部清除**；与专业版共用 `quantlens.priceLines.{symbol}` 存储
- 自动支撑/阻力、模拟练习止损止盈线为系统生成，**不能**在画线菜单里删除

**智能解读 / 小白版**：指标 Chip 悬停显示白话说明；小白版固定单图并隐藏 EMA/BOLL/VP 等专业开关，保留成交量（显示为「买卖活跃度」）。

### 5.3 K 线与分屏（ChartWorkspace / ChartPaneGrid）

| 模式 | 行为 |
|------|------|
| 单图 | 主 WS 品种；完整副图；完整 OHLC 图例 |
| 双图 | 主周期 + 副周期；角标可改副图周期 |
| 四图 | 默认 `1m/15m/1h/1d`；每格角标独立换周期；**激活格**右上角小圆点（非粗青框） |

**交互**

- 十字光标：单图显示 O/H/L/C、EMA；多图 **跨周期时间联动**（对齐最近 K 线时间）
- **Alt + 点击**：添加水平价位线
- 金叉/死叉箭头标记（悬停显示详情）
- AI 诊断/形态识别可注入支撑阻力参考线

**紧凑图例（多图）**：仅收 C + 涨跌幅；EMA 以色点 + Tooltip；关闭 LWC 轴上多余标签，避免与图例重叠。

**加载与错误**

- 图表区顶部 **全局错误条**：行情拉取超时；「重新加载」触发 `market.retry()` 并递增 `paneReloadToken` 重拉各辅助周期
- 全局错误展示时，子格**不显示单独重试**，统一文案「数据源超时」
- 窗格状态：网格底 + 加载环 / 失败 HUD（无灰卡片块）

### 5.5 左栏自选（Watchlist）

- **A 股自选**分组、迷你 sparkline、现价、涨跌幅
- **搜索**：代码/名称，`/catalog/search` 全市场检索并加入自选
- **条件选股 ⛃**：卡片式预设、自选/全市场切换、参数 Chips；小白版白话文案（`ScreenerModal` + `GET /screener/universe` 等后端接口）

- **大盘指数条**：上证50、沪深300、创业板等快捷切换
- **市场温度条**：基于自选涨跌家数的简易情绪

### 5.6 右栏（RightDock）

顶部常驻 **MarketHealthCard**（多空体检）：折叠评分条，展开分项进度与关键位 Chips；小白版为**交通灯式强弱**与一句话总结。

**Tab 页签（专业版）**

| Tab | 功能 |
|-----|------|
| 信号 | SignalLog：范围「当前标的」\|「自选」；白话模式下标题为「提醒记录」 |
| 持仓 | 模拟开仓：入场/止损、资金与股数、仓位比例、买卖；止损风控卡 |
| 回测 | BacktestPanel：多策略模板、参数滑条、净值对比、自选批量榜 |
| 笔记 | TradingJournalPanel：开仓/平仓/观察标签，复盘正文；K 线可显示笔记标记 |

### 5.8 系统设置（AlertSettings）

**外观**：涨跌配色 — 胶囊分段（自选 / 红涨绿跌 / 绿涨红跌）

**策略预警 / 涨跌提醒**：EMA、RSI、布林等；小白白话标题

**数据备份**：幽灵按钮 — 导出全部 JSON、从备份恢复、导出模拟成交/复盘笔记 CSV；说明 SQLite 路径供手动备份

**通知**：提示音、桌面通知（Tauri）、Webhook URL + 测试、可选触发时模拟买入 100 股

**同步**：启动时 `bootstrapUserDataSync()` 拉取/推送；画线键以时间戳合并；清除画线后写回服务端避免久未登录又被旧数据覆盖

**样式**：基础在 `global.css`，增量在 `overrides.css`（设置弹窗、标记价位菜单、练习滑块等）

### 5.9 预警与信号链路

1. 后端 WS 推送 K 线 + `scan_signals` 结果

3. 触发：声音、`relayWebhook`、Tauri `notify_signal`  
4. 自选 scope：watchlist 标的并行拉 K 线并 `backfillEmaSignals` 历史信号

## 8. 数据与持久化

### 8.1 服务端 SQLite（`backend/data/quantlens.db`）

| 用途 | 说明 |
|------|------|
| K 线缓存 | 采集器写入，降低重复拉取 |
| `user_data` | JSON 文档键值，支持同步键见下表 |

**可同步键（`SYNC_KEYS`）**

| 键名 | 内容 |
|------|------|
| `quantlens.watchlist.extra` | 自选扩展 |
| `quantlens-paper-trades` | 模拟成交 |
| `quantlens-trading-journal` | 复盘笔记 |
| `quantlens-alert-rules` | 预警规则 |
| `quantlens-price-color-mode` | 涨跌配色 |
| `quantlens-novice-assist` | 智能解读开关 |
| `quantlens.priceLines.{symbol}` | 各标的画线（前缀匹配） |

### 8.2 浏览器 localStorage

与上表键**双写**；离线仍以 localStorage 为准，联网后与 `/sync` 合并。

### 8.3 其他本地状态

| 项 | 存储 |
|----|------|
| 上次浏览标的 | `quantlens.lastSymbol` |
| 图表周期 / 布局 | React 状态 + 部分持久化钩子 |

## 9. 行情、指标与策略引擎

### 9.1 数据源路由

| 标的示例 | 数据源 |
|----------|--------|
| `600519`、`510300` | AKShare（东财分钟线；ETF 受限时新浪回退） |
| `BTC/USDT` | CCXT（默认 KuCoin，可环境变量切换） |
| `AAPL` | yfinance |

### 9.2 指标（`indicators.py`）

EMA、RSI(14)、MACD、布林带、ATR 等；前端按开关叠绘。

### 9.3 策略规则（`rules.py`）

与设置开关对齐：RSI 超卖/超买、布林轨突破、EMA 金叉死叉。

### 9.4 回测（前端 `backtestEngine.ts` / `BacktestPanel`）

对当前标的、当前 K 线序列执行 EMA 交叉简易回测，输出收益、胜率、回撤、权益曲线等（非 tick 级机构回测）。

## 11. 异常与故障处理

| 现象 | 原因 / 处理 |
|------|----------------|
| 页面布局塌陷、K 线区无限变长 | **勿截断 `global.css`**；从 Git 恢复；确认 `overrides.css` 已加载；`chart-stack` 使用 `min-height:0`；强刷 |
| 标记删不掉又出现 | 久未登录后 `/sync` 拉回旧画线 → 用「全部清除」后写回；或检查后端 `user_data` |
| 切换 ETF 超时 | 东财限流；等待后点图表区「重新加载」；重启后端 |
| 品牌绿点 vs 文案「已收盘」 | 盘后链路仍在线属正常；悬停应见「已收盘」说明 |
| WebSocket 断开 | 点击失败状态重连；确认 `python run.py` 运行 |
| 四图周期工具栏无效 | 先点击要操作的子图（激活小圆点），再改周期 |
| K 线区空白 | 父容器高度为 0 多为样式缺失；检查 `.chart-area` / `.layout` flex |
| 预警无 Webhook | 设置开启推送、填写 URL、点「测试」 |
| `npm run build` 失败 | 修复 TypeScript 错误后再打包 |
