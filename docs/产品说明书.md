# QuantLens 产品说明书

**版本**：0.1.x（`cursor/focus-mode-toolbar-signals` 功能线）  
**产品定位**：轻量级 A 股取向实时行情监控、技术指标分析与模拟交易复盘终端  
**技术形态**：Tauri + React（桌面）/ 浏览器（Vite 开发）+ Python FastAPI 行情引擎

---

## 1. 产品概述

QuantLens 面向个人投资者与量化爱好者，在单机环境下提供：

- 实时 K 线、技术指标与策略信号
- 自选监控、指数风向与简易选股
- 多周期分屏、AI 结构化研报、模拟持仓与笔记复盘

默认市场模式为 **A 股**（红涨绿跌）；后端可扩展加密货币、美股（见 README）。

---

## 2. 运行环境与启动

| 组件 | 要求 |
|------|------|
| 前端 | Node.js 18+，`frontend` 目录 `npm run dev`（默认 **http://localhost:1420**） |
| 后端 | Python 3.11+，`backend` 虚拟环境 `python run.py`（默认 **http://127.0.0.1:8765**） |
| 桌面 | Rust + Tauri（可选）`npm run tauri dev` |

**注意**：前端白屏时多为 dev 端口 HMR 异常，请重启 `npm run dev` 并 **Ctrl+F5** 强刷。  
ETF（如 510300）在东财限流时，引擎会优先尝试新浪分钟线；仍失败时请等待数分钟后 **重新加载**。

## 3. 界面总览

```
┌─────────────────────────────────────────────────────────────────┐
│ 顶栏：标的 | 周期标签 | 连接状态 | 分屏 | 智能解读 | AI诊断 | 现价  │
├──────────┬──────────────────────────────────────┬────────────────┤
│ 左栏自选  │  工具栏（周期/指标/画线）              │  多空体检折叠条  │
│ 搜索/选股 │  K 线主图 + VOL + MACD/RSI 副图       │  信号|持仓|回测… │
│ 指数条    │  （支持单图/双图/四图）                │                │
│ 市场温度  │                                      │                │
└──────────┴──────────────────────────────────────┴────────────────┘
```

- **左栏宽度**约 230px，**右栏**约 248px；专注模式 **F** 可同时收起两侧。
- **四图模式**进入时自动收起左右栏，扩大图表可视区。

## 4. 功能说明

### 4.1 顶栏（TopStatusBar）

| 功能 | 说明 |
|------|------|
| 标的名称/代码 | 显示中文名与交易所后缀（如 600519.SH） |
| 周期标签 | 与当前 **激活图表格** 的周期同步（单图=主周期；四图=点击选中的子图） |
| 连接胶囊 | WebSocket 状态、心跳、重连次数；可手动重连 |
| 分屏布局 | 单图 ▢ / 双图 / 四图 ▦ |
| 智能解读 | 开关指标白话 Tooltip、盘面简要条；天蓝指示灯=开启 |
| AI 诊断 | 打开结构化研报弹窗 |
| 系统设置 | 齿轮图标 → 预警与配色 |
| 现价 | 红涨绿跌，含涨跌额与百分比 |

### 4.2 图表区

**周期**：1m、5m、15m、1h、4h、1d（工具栏与快捷键 **1–6** 作用于当前激活格）

**主图指标**（可组合）：

- EMA（20/50）
- 布林带 BOLL
- 成交量 VOL
- 量价分布 VP（可选）

**副图**（单图模式）：MACD 或 RSI 二选一；双图/四图默认隐藏副图以节省高度。

**交互**：

- 十字光标：悬停显示 O/H/L/C、EMA；多图模式下 **跨周期时间联动**（对齐最近 K 线）
- **Alt + 点击** 主图：添加水平价位线；画线工具菜单支持现价/±2% 止损止盈
- 金叉/死叉：主图箭头标记（降噪，文案悬停显示）
- 支撑/阻力等参考线：AI 诊断或形态识别可一键画入主图

**分屏**：

| 模式 | 行为 |
|------|------|
| 单图 | 主 WebSocket 品种 + 完整副图 |
| 双图 | 主周期 + 副图周期（角标可选 15m/1h/1d 等） |
| 四图 | 默认 1m/15m/1h/1d；每格可点角标单独换周期；点击格激活（蓝框）；顶栏周期随激活格变化 |

### 4.3 左栏自选（Watchlist）

- **A 股自选**：分组列表，含迷你 sparkline、现价、涨跌幅
- **搜索**：代码 / 名称 / 全市场搜索，可一键加入自选
- **条件选股 ⛃**：在自选池内按预设筛选（涨幅>3%、RSI 超卖、MACD 金叉、站上 EMA20）
- **大盘指数条**：上证50、沪深300、创业板等快捷切换
- **市场温度**：基于自选涨跌家数的简易情绪条
- **收起 ◂**：与专注模式联动；展开窄轨 **▸**

交易时段外报价可能为「—」；盘中才显示「实时报价获取中」提示。

### 4.4 右栏（RightDock）

#### 多空体检（MarketHealthCard）

- 折叠条：综合评分、支撑简述
- 展开：趋势/动能/位置分项进度条与关键位 Chips

#### 信号（SignalLog）

- 范围：**当前标的** | **自选**（自选会回填 EMA 类历史信号）
- 最多展示 8 条；盘中预警带 **NEW** 点；历史信号弱化显示

#### 持仓（模拟）

- 开仓价 / 止损价（现价、-2%、支撑位快捷）
- 总资金 / 数量（元、股后缀）
- 仓位比例 25/50/75/全仓（A 股 100 股整数）
- 市价买入 / 平仓卖出
- 止损填写后：**预估亏损** + **建议股数** 风控卡

#### 回测

- 当前标的 EMA 金叉/死叉简易回测：累计收益、胜率、盈亏比、最大回撤等
- 持仓回合卡片展示最近模拟交易

#### 笔记

- 复盘笔记：开仓 / 平仓 / 观察标签，Markdown 式记录，本地持久化

#### 盘口（非 A 股独占模式时）

- 买卖五档深度（后端 `/depth`）

### 4.5 AI 结构化研报

- 宽幅卡片布局：局势 + 评分、关键点位（红阻绿撑）、多周期共振胶囊、观察剧本
- **一键画入主图**：支撑/阻力水平线
- 复制研报、关闭 ✕
- 数据：`/radar` 多周期 + 本地 K 线结构化引擎；不暴露「加载中」占位文案

### 4.6 系统设置

**外观**：涨跌配色三段——自动 / 红涨绿跌 / 绿涨红跌  

**策略预警**（Switch）：EMA 金叉死叉、RSI 超买超卖、布林上下轨  

**通知**：提示音、Webhook 推送（Server酱/飞书/钉钉等 POST）；URL 全宽 + **测试** 按钮  

配置保存在浏览器 `localStorage`。

## 5. 快捷键

| 按键 | 功能 |
|------|------|
| **F** | 专注模式（两侧栏同时开合） |

## 6. 后端 API 摘要

| 方法 | 路径 | 用途 |
|------|------|------|
| GET | `/health` | 健康检查 |
| GET | `/klines?symbol=&interval=` | REST 拉取 K 线快照 |
| WS | `/ws?symbol=&interval=` | 实时行情推送 |
| GET | `/quotes` | 批量报价 |
| GET | `/catalog/search` | 标的搜索 |
| GET | `/radar?symbol=` | 多周期共振帧 |
| GET | `/diagnose?symbol=&interval=` | 文字诊断（备用） |
| GET | `/depth?symbol=` | 盘口 |
| POST | `/webhook/relay` | Webhook 转发测试/推送 |

默认端口：**8765**。前端通过 `VITE_API_URL` / `VITE_WS_URL` 配置。

## 8. 策略与指标（引擎侧）

**指标**：EMA、RSI(14)、MACD、布林带、ATR（`backend/app/indicators.py` + 前端 Lightweight Charts 叠绘）

**默认扫描规则**：RSI 超卖/超买、布林轨、EMA 金叉死叉（可与设置开关对齐）

**A 股数据源**：AKShare（东财分钟 + 新浪回退）；Listed ETF（51/15 开头等）走 ETF 专用接口

## 9. 常见问题

| 现象 | 处理 |
|------|------|
| 切换 ETF 超时 | 重启后端；等待东财限流解除；点「重新加载」 |
| 页面纯白 | 重启 `npm run dev`，强刷 1420 |
| WebSocket 断开 | 顶栏连接胶囊 → 重连；确认 `python run.py` 已运行 |
| 四图顶栏周期不对 | 先 **点击** 要操作的子图（蓝框），再点周期按钮 |
| 预警无 Webhook | 设置中开启推送并填写 URL，点「测试」 |
